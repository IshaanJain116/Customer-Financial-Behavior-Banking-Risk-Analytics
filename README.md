# 📊 Customer Financial Behavior & Banking Risk Analytics

An end-to-end Banking Analytics project built using **Python, SQL, and Power BI** to analyze customer financial behavior, banking trends, deposits, loans, and risk patterns for data-driven business decision making.

---

# 🚀 Project Highlights

✔ Performed detailed Exploratory Data Analysis (EDA) using Python  
✔ Solved real-world banking business problems using SQL  
✔ Built an interactive multi-page Power BI dashboard  
✔ Analyzed customer income, deposits, loans, and engagement patterns  
✔ Identified high-risk and high-value customer segments  
✔ Created business insights for strategic banking decisions  

---

# 🎯 Business Objectives

The main objectives of this project are:

- Analyze customer financial behavior
- Study loan and deposit trends
- Identify high-risk customers
- Understand customer segmentation patterns
- Compare banking product usage
- Generate actionable banking insights
- Build an interactive dashboard for business reporting
