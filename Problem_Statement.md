# 📌 Problem Statement

Banks generate massive amounts of customer and financial data every day through transactions, deposits, loans, savings accounts, credit card usage, and other banking activities. However, extracting meaningful insights from this data is a major challenge for financial institutions.

The objective of this project is to analyze customer financial behavior and banking risk patterns using data analytics techniques. This project focuses on understanding how customer income, deposits, loans, savings, and engagement activities impact overall banking performance and customer segmentation.

Using Python for Exploratory Data Analysis (EDA), SQL for business query analysis, and Power BI for dashboard visualization, this project aims to identify high-value customers, detect potential risk patterns, analyze financial trends, and generate actionable business insights for better decision-making.

The project addresses the following business questions:

- How are customers distributed across different income levels?
- Which customers have high loan exposure and financial risk?
- Which customer segments contribute most to bank deposits?
- How does customer engagement affect banking activity?
- Which nationalities and customer groups contribute most to banking revenue?
- How can banks identify profitable and high-risk customer segments?
- What financial trends can support strategic banking decisions?

This project helps demonstrate how data analytics can support the banking sector in improving customer understanding, risk management, and business intelligence reporting through data-driven insights.
